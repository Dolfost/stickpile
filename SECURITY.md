# Security policy

## Supported versions

Only the latest release receives security fixes. Fixes land on `main` first
and ship in the next release.

## Reporting a vulnerability

Do not open a public issue. Report it privately through GitHub's private
vulnerability reporting: the **Report a vulnerability** button on the
[Security tab](https://github.com/Dolfost/stickpile/security), or directly at
<https://github.com/Dolfost/stickpile/security/advisories/new>.

Please include:

- the affected version or commit,
- how to reproduce it (a request, a file, a config),
- what an attacker gains.

The report stays private until a fixed release is out. You will be credited in
the advisory unless you prefer not to be.

The threat model, including what is out of scope, is in
[docs/security.md](docs/security.md#threat-model).
