# Screenshots

Screenshots of the web UI for the top-level README, each in a light and a
dark version (the page follows `prefers-color-scheme`, and so does the
README on GitHub). They show a demo server with three sets, a second and
third user who liked some items, and a month of copy history; the AI
suggestions are real CLIP output.

The demo stickers are made from [Noto Emoji](https://github.com/googlefonts/noto-emoji)
images (© Google, Apache License 2.0) with captions set in
[Roboto](https://github.com/googlefonts/roboto-3-classic) (SIL Open Font
License 1.1).

Captured with headless Chromium at 1280 px wide and a device scale of 2,
then reduced with `pngquant --quality 75-92` and `oxipng -o 4`.
